# 模板与必要工具

`reference-workbook.tex` 是**当前规则下的参考骨架**，不是一键批准的八册母版。每科/每种代表页型都必须用真实内容渲染、逐页查看后才能继续扩大。

使用前必须同时读取 `版式规范.md`、`四科细节审校.md`、`交付验收.md`：
- 正式品牌为**青云阁教育**；
- 页脚简洁，不使用随机鸡汤/轮换名言；
- 教师版不印“源教师资料”等内部来源标签；
- 数学主观题用纯空白作答区，不调用横线答题模板；空白高度按实际步骤决定；
- 其他学科需要横线/格线时才调用对应宏；
- 续页使用轻量标记，不复制完整大标题块；
- 题目来源、图源、重绘/核验/校对等元说明不进入成书；
- 教师提示框不是每题标配；
- 数学图形能可靠还原时优先统一矢量出版质量；
- 关键公式和多步推导使用正规展示/对齐环境。

当前数学立体几何样张只验证一种页型，不代表此模板已适配语文长阅读/作文、英语完形/写作、政治长材料/漫画图表、数学选择填空/函数统计图。进入各科正式生产时先验证代表页型。

旧工程工具可从归档分支按需取回；必须包含运行所需依赖，不能复制一个孤立脚本就宣布可运行。只为实际重复工作增加小工具，如编号、目录、源位置统计、缺字检查、文件打包；不恢复整套工程作为生产前置条件。
