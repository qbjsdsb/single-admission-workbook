# 模板与必要工具

`reference-workbook.tex` 是**当前规则下的参考骨架**，不是一键批准的八册母版。每科/每种代表页型都必须用真实内容渲染、逐页查看后才能继续扩大。

## 2026-10-04模板复核（二轮后）

已复核并修正TeX参考骨架：书本线描图标现在固定在每页右上运行页眉（含plain页）；页脚只保留“青云阁教育”和页码；章入口只有一个正文同名标题，不强制 clearpage；提示标签必须显式指定，避免默认方法框。骨架仍需结合真实题型渲染检查，不能单凭宏文件批准母版。

当前数学立体几何样张二轮版已按本骨架方向实际成页：学生5页、教师4页。它仅验证数学几何主观题页型；语文、英语、政治以及数学选择填空/公式/函数统计图等页型仍待各自真实内容验收。


使用前必须同时读取 `章节分类.md`、`章节编排与续接.md`、`版式规范.md`、`四科细节审校.md`、`交付验收.md`。

## 当前模板必须服从的硬规则
- 正式品牌为**青云阁教育**；
- 页脚简洁，不使用随机鸡汤/轮换名言；
- 教师版不印“源教师资料”等内部来源标签；
- 数学主观题用纯空白作答区，不调用横线答题模板；空白高度按实际步骤决定；
- 其他学科需要横线/格线时才调用对应宏；
- 续页使用轻量标记，不复制完整大标题块；
- 题目来源、图源、重绘/核验/校对等元说明不进入成书；
- 教师提示框不是每题标配；
- 数学图形能可靠还原时优先统一矢量出版质量；
- 关键公式和多步推导使用正规展示/对齐环境。

## 固定视觉骨架
模板层面优先固定以下内容，不能让生成脚本逐页随意改变：
- A4版心与页边距；
- 页眉高度及左右信息位置；
- 右上角线描书本图标的位置、大小、线宽；
- 章/节标题起点；
- 正文主栏宽度；
- 页脚品牌与页码位置；
- 题号、小问、选项的基础悬挂/缩进。

正文样式只保留少数稳定字体层级和间距档位。强调色只承担导航和必要重点，不为每页单独设计装饰色块。

## 页型而不是“一页一个设计”
模板应逐步沉淀少量真实页型：
- 数学：选择/填空密集、普通解答、图形解答、公式/推导密集、教师解析；
- 语文：语言基础、长现代文、古代诗文、主观简答、作文、教师解析；
- 英语：词汇/语法、完形、长阅读/广告表格、拼写、写作、教师解析；
- 政治：选择、长材料、图表/漫画、主观材料题、教师解析。

所有页型共享品牌、字体、间距、页眉页脚、题号和色彩系统。学生/教师版保持同一视觉家族；教师版只改变内容密度与解析区，不另做完全不同的视觉系统。

当前数学立体几何样张只验证一种页型，不代表此模板已适配语文长阅读/作文、英语完形/写作、政治长材料/漫画图表、数学选择填空/函数统计图。进入各科正式生产时先验证代表页型。

每个4—8页批次完成后，除逐页检查，还必须做一次缩略图/多页并排检查；若标题、页脚、图标、字号、同类图尺寸、缩进或页面密度系统性跳变，优先修模板/样式，不要逐页手工打补丁。

## 章节结构不能由模板决定
当前正式章节框架为语文7章、数学9章、英语9章、政治12章，具体见 `章节分类.md`。模板只负责视觉和排版，不能因为模板里已有某个section结构就强迫内容迁就模板。

旧工程工具可从归档分支按需取回；必须包含运行所需依赖，不能复制一个孤立脚本就宣布可运行。只为实际重复工作增加小工具，如编号、目录、源位置统计、缺字检查、文件打包；不恢复整套工程作为生产前置条件。
