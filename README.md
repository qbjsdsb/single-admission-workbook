## GitHub 的新职责
GitHub 从现在起只保留**长期稳定规则**、章节框架、版式规范、历史交接和提示词备份。

不再承担：
- 每批实时进度；
- 每个恢复点；
- 当前有效 Library 文件 ID；
- 邮件发送状态；
- 日常生产日志。

新 Work 窗口**不需要先访问 GitHub**。GitHub 不可用也不能阻塞生产。只有用户明确要求同步，或长期规则发生重大稳定变化时再更新本仓库。

## 外部工具新策略
- **Gmail：默认不用。** 样张直接放 ChatGPT Library 给用户审阅；只有用户明确要求“发邮件”时才发送。
- **Google Drive：可选二级备份。** 不再作为每批必经步骤；里程碑备份或用户明确要求时再用。
- **GitHub：静态规则备份。** 不再每批更新。

即使外部工具出现授权、登录或网络问题，Library 内生产继续。单点失败不得成为全项目停止条件。
