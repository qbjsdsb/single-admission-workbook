## 统一视觉语言（2026-10-04）
用户明确要求**每一页风格统一**。统一不是每页完全同版，而是全书遵守同一套视觉语法：
- 固定版心/页边距、页眉、右上角线描书本图标、标题起点、正文主栏、页脚、题号/小问/选项缩进；
- 字体控制在少数稳定层级，间距使用少量固定档位；
- 强调色只承担导航和少量重点作用；
- 同类图使用稳定尺寸与线条语言；
- 学生/教师版保持同一视觉家族；
- 四科各用少量稳定代表页型，不让AI逐页重新设计。

每个4—8页编辑批次除逐页检查外，必须再做**缩略图/多页并排检查**，观察页面密度、标题起点、页眉页脚、图标、色彩、同类图、缩进和提示框是否突然跳变。完整规则见 `版式规范.md` 与 `交付验收.md`。
