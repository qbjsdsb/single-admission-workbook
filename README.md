目标：为**青云阁教育**制作语文、数学、政治、英语各一册学生练习册和一册教师解析册，共八册，最终每册交付 Word 与 PDF。
本仓库是 AI 的指导和交接记忆。题目、答案、图片、书页和可续编文件保存在 ChatGPT 云端文件夹“体育单招八册工作总目录”；Google Drive 用于已有成果续接和阶段备份。

## 接手顺序
1. 读 AGENTS.md、当前进度.md、反馈与改进.md。
2. 读对应的 四科交接/科目.md，以及资料位置.md。
3. 从实际保存成果恢复状态；小批识别、核验、分类、编辑、逐页检查、保存，然后继续。
4. 识别和编辑前读 编辑判断与准确性.md、四科细节审校.md；成书前读 章节分类.md、章节编排与续接.md、版式规范.md、交付验收.md；保存时执行 备份规则.md；按 小批进度与成果展示.md 向用户呈现实际成果。
5. 用户最新明确意见优先；有待确认的设计方向不得写成已批准样张。
