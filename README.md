本仓库是 AI 的指导和交接记忆。题目、答案、图片、书页和可续编文件保存在 ChatGPT 云端文件夹“单招练习册云端成书”；Google Drive 用于已有成果续接和阶段备份。

## 接手顺序
1. 读 AGENTS.md、当前进度.md、反馈与改进.md。
2. 读对应的 四科交接/科目.md，以及资料位置.md。
3. 从实际保存成果恢复状态；小批识别、核验、分类、编辑、逐页检查、保存，然后继续。
4. 识别和编辑前读编辑判断与准确性.md、四科细节审校.md；成书前读章节分类.md、章节编排与续接.md、版式规范.md、交付验收.md；保存时执行备份规则.md。
用户最新明确意见优先；有待确认的设计方向不得写成已批准样张。

## 当前重点
先整理已可靠识别的题目，并制作少量内容的成对样书，落实按内容和题型分章、字体层次、舒适排版及右上角线描书本图标。之后按相同规则连续推进。
不得把“已提取”“有PDF”“脚本通过”当作八册完成。
