# 体育单招四科八册 · 编辑与交接

目标：为**青云阁教育**制作语文、数学、政治、英语各一册学生练习册和一册教师解析册，共八册，最终每册交付 Word 与 PDF。
本仓库是 AI 的指导和交接记忆。题目、答案、图片、书页和可续编文件保存在 ChatGPT 云端文件夹“体育单招八册工作总目录”；Google Drive 用于已有成果续接和阶段备份。

## 接手顺序
1. 读 AGENTS.md、当前进度.md、反馈与改进.md。
2. 读对应的 四科交接/科目.md，以及资料位置.md。
3. 从实际保存成果恢复状态；小批识别、核验、分类、编辑、逐页检查、保存，然后继续。
4. 识别和编辑前读 编辑判断与准确性.md、四科细节审校.md；成书前必须读 **章节分类.md、章节编排与续接.md、版式规范.md、交付验收.md、外部经验吸收与四科成书建议.md**；保存时执行 备份规则.md；按 小批进度与成果展示.md 向用户呈现实际成果。
5. 用户最新明确意见优先；有待确认的设计方向不得写成已批准样张。

## 正式章节框架（2026-10-04）
章节骨架按**2023版体育单招文化考试大纲 + 当前真实题源/备考资料**执行。详细节级结构见 `章节分类.md`。

当前正式章数：
- **语文：7章**；
- **数学：9章**；
- **英语：9章**；
- **政治：12章**。

原则：**考纲定骨架，真实题源定容量，备考资料补充知识卡/解析/校核。** 不按原卷年份、来源文件或原讲义目录拼书；映射真实题量后再做最后一次合节/拆节；不为目录对称制造空架子小节。

完整阅读、完形、古代诗文、政治材料题及相互依赖的小问整组保留。政治新闻材料不自动等于时事题；英语机构词表不冒充官方完整词表；数学公式/高频资料、政治必背资料、语文知识梳理不另造一级章。

## 统一视觉语言
用户要求**每一页风格统一**。统一不是每页完全同版，而是全书遵守同一套视觉语法：
- 固定版心/页边距、页眉、右上角线描书本图标、标题起点、正文主栏、页脚、题号/小问/选项缩进；
- 字体控制在少数稳定层级，间距使用少量固定档位；
- 黑灰为主，同一品牌主强调色，科目只做轻量识别；
- 同类图使用稳定尺寸与线条语言；
- 学生/教师版保持同一视觉家族；
- 四科各用少量稳定代表页型，不让AI逐页重新设计。

每个小批除逐页检查外，必须做**单册缩略图检查**；四科八册样张还必须做**八册横向并排检查**，确认没有某一本像“另一个设计师”。

## 外部经验如何吸收
新增 `外部经验吸收与四科成书建议.md`。公开体育单招课程、教材和真题讲解只用于吸收产品/教学组织经验，例如：
- 知识模块→真实题训练→复盘→阶段检测的短闭环；
- 真题按知识点进入章节，而不只堆在书末；
- 解析质量优先于题量堆砌；
- 页面支持体育生短时高频使用；
- 专项训练与90分钟整卷节奏训练分工明确；
- 政治主观题重材料对应，不用万能模板替代理解。

非官方网页、机构宣传、所谓“必考/押题/命中率”不得改写官方考纲、题面和答案。
