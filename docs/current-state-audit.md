# 当前状态审计

> 审计日期：2026-09-22
> 审计对象：`qbjsdsb/single-admission-workbook` 的 `main` 与 `research/foundation-v1`  先行基础设施分支

## 1. 审计边界

本审计只覆盖公开仓库、公开可引用的考试大纲/管理文件，以及本机历史教研资料的目录级和代表性文件级检查。历史资料仍保留在本机研究根目录，仓库不复制原始试卷、教师批注原件、整包压缩文件或包含本机绝对路径的台账。

公开仓库：<https://github.com/qbjsdsb/single-admission-workbook>
本地研究根目录在文档中统一称为 `LOCAL_RESEARCH_ROOT`，其真实路径不写入公开数据文件。

## 2. 公开仓库基线

| 项目 | 当前事实 | 影响 |
|---|---|---|
| 默认分支 | `main` | 仍可保留为稳定入口；基础设施改造放在研究分支 |

| 初始定位 | 语文、政治 LaTeX 习题册公开骨架 | 必须纠正为语文、数学、政治、英语四科基础设施 |
| 初始模板 | `src/main.tex` 单文件样张 | 需要拆出内容、公共版式、四科规范和学生/教师入口 |
| 原有标注 | `\overset` 上置圆点 | 与中文“字下点”要求不符，须改为独立可测试的下标记 |
| 原有构建 | `scripts/build.ps1` 直接编译同一入口两次 | 不能表达内容校验、学生/教师同源、字体和视觉回归 |
| 自动化 | 尚无 GitHub Actions、schema、fixtures、发布门槛 | 需要先有可重复的小样本流水线，再谈批量导入 |
| 题源数据 | 尚无公开题源库 | 题源台账先采用本地私有映射与公开匿名化 fixture 分离 |

初始远程仓库只有少量说明、技能规则、构建脚本和 LaTeX 样张；没有 issue、PR、工作流或完整内容模型。因此本阶段是基础设施接管，不是对既有题库做机械搬运。

## 4. 当前已确认的事实与未完成事项

### 已确认

- 2023 版文化考试大纲覆盖语文、数学、政治、英语四科；官方页面称 2021 版同时废止。
- 2026 招生管理文件仍按四科、每科 150 分、合计 600 分组织文化考试；每科考试时长为 90 分钟。
- 语文、政治的 2022–2024 本地资料具有较完整的教师复核线索，但不能据此把本地转录称为官方原卷。
- 本地已经有 B5、颜色/灰度、文本结构和部分逐页检查经验；这些经验需要变成仓库中的可执行门槛。
- 本机 XeLaTeX 已验证可执行，当前实际安装路径由本机构建脚本发现，不作为仓库固定路径。

### 尚未完成

- 全部本地题目逐题语义审核、答案审核和解析审核。
- 数学全量公式、符号、几何图形和解答过程的结构化核验。
- 英语旧 DOC/DOCX 转换后的段落、下划线、选项、连字符和字体核验。
- 2025–2026 回忆题或模拟题的逐题时效与可用性判断。
- 四科题源批量导入、近重复检测、OCR 和自动知识点分类。
- 公开仓库的首个小样本 PDF 在 CI 和不同机器上的字体一致性验证。

## 5. 硬约束

1. `LOCAL_RESEARCH_ROOT` 下的原始资料只读；只生成旁路索引、哈希、报告和公开匿名化夹具。
2. 任何题目都不能只保留“改后文本”；原始观察值、问题、修订建议、证据和核验状态必须可回溯。
3. “教师审核版”“本地整理稿”“回忆题”“模拟题”与“官方文件”必须在数据中分开，不靠文件名猜测。
4. 章节、题号、版面位置不能作为永久身份；永久身份使用稳定 `question_id`，年份/来源出现使用 `occurrence_id`。
5. 学生版和教师版必须由同一份结构化内容生成；答案和解析属于教师视图，而不是另一套题目。
6. B5 是打印 profile，不得悄悄成为内容字段或题目截断理由。
