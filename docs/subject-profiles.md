# 四科内容与版式规范

四科使用同一 provenance/content/QA 骨架，但每科有独立的内容检查器、标记规则和发布风险。

## 语文

- 内容：语言文字运用、文学常识/作品、现代文阅读、文言文/古诗词、写作。
- 版式：中文长段落、文言文与注释、拼音/字音、字下点、引用层级、作文答题区。
- 重点 QA：字下点位置、古文原句与译意分离、材料/题干不串段、作文格线和页底留白。
- 题源风险：二手转录、异体字、标点和答案依据缺失；教师审核需拆为题面/答案/解析三项。

## 数学

- 内容：集合与逻辑、函数、不等式、三角、数列、向量、解析几何、立体几何、计数与概率。
- 版式：公式、分式、上下标、矩阵/表格、几何图、解答步骤和单位。
- 重点 QA：公式可编译、符号含义不丢失、图形与题干对应、答案步骤不被分页截断、文本提取仍可读。
- 题源风险：扫描 OCR 符号混淆、负号/根号/指数错误、答案只给结果没有可评分步骤。

## 政治

- 内容：新时代中国特色社会主义、经济与社会、政治与法治、哲学与文化、时事政治。
- 版式：材料框、分层设问、要点式答案、引用/依据、长答案留白。
- 重点 QA：材料题分值与得分点对应、题干/选项不截断、时事窗口和适用年份显式显示、答案与解析分开。
- 题源风险：时事过期、术语混用、模拟卷总分/分值错误、回忆题或二手整理误称官方。

## 英语

- 内容：语音、基础词汇与短语、语法、阅读、词汇/语法填空、短文理解、书面表达。
- 版式：IPA/重音、英文词形、对话、完形/填空线、短文段落、大小写、连字符和中英混排。
- 重点 QA：旧 DOC/DOCX 转换不丢段落和选项、行距和断词稳定、空格与下划线可写、英文文本可提取。
- 题源风险：转录大小写/标点、选项顺序、词形答案、字体缺失和中英文混排溢出。

## 共用规则

四科都必须拥有独立 subject profile 文件或等价配置；不得用语文模板换标题后声称已支持数学、政治或英语。任何科目的 `student_release` 都要通过本学科内容检查和共用 Q0–Q8 门槛。
