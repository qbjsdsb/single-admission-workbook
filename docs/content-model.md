# 内容模型与渲染边界

## 1. 内容流水线

```text
Raw Source
  -> Provenance
  -> Normalized Content
  -> Semantic AST
  -> Renderer
  -> Student PDF / Teacher PDF
```

原始材料、题源证据、规范化文本、语义结构和版式输出必须有边界。渲染器不能偷偷修正文意；内容脚本不能通过字符串替换伪造审核结论。

## 2. 核心实体

| 实体 | 作用 | 关键身份 |
|---|---|---|
| `Source` | 材料、出处和哈希 | `source_id` |
| `Question` | 脱离年份和版式的题目概念 | `question_id` |
| `Occurrence` | 题目在某来源中的一次出现 | `occurrence_id` |
| `Revision` | 原值到规范化值的可追踪修订 | `revision_id` |
| `Material` | 阅读材料、政治材料、英语短文等 | `material_id` |
| `Stem` | 题干及其段落/标记结构 | `stem_id` |
| `Choice` | 选项文字、标签和排序 | `choice_id` |
| `Blank` | 填空位置和答案槽 | `blank_id` |
| `Answer` | 参考答案、答案类型和依据 | `answer_id` |
| `Explanation` | 解析、得分点、错误点 | `explanation_id` |
| `Verification` | 题面/答案/解析/分值/时效核验 | `verification_id` |
| `PublicationView` | 学生版或教师版视图 | `view_id` |

## 3. 内容与版式分离

内容层只描述：题干、材料、选项、空格、分值、答案、解析、考点、难度、来源和核验。版式层才描述：B5、页边距、字号、颜色、框线、页眉、答题区、分页提示和教师版答案显隐。

`question_id` 不包含章节名、题号、年份或页码。章节和题号是 `occurrence` 或出版视图属性；同一道题可以进入不同章节或样册而不改变身份。

## 4. 学生/教师同源

学生视图：题面、材料、选项、答题区和必要的分值。
教师视图：学生视图的全部内容，加上答案、解析、依据、得分点、错误标签和审核状态。

两者必须由同一份 fixture/规范化记录生成。若学生版和教师版的题干、选项、材料或分值不一致，构建应失败或发出明确差异报告。

## 5. 不允许自动语义改写

自动化可以做格式规范化、字段校验、哈希、去重候选、题号重排和版式渲染；不可以在没有新证据和人工审核事件的情况下改写题意、答案、政治时事结论、古文句意、英语语法答案或数学推导。
