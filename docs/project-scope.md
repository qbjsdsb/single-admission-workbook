# 项目范围与后续计划

## 正式目标

建设体育单招文化考试语文、数学、政治、英语四科长期可维护、可验证、可追溯、可重复生成的习题册基础设施。第一阶段只证明研究成果、来源边界、内容模型、渲染器和 QA 能够闭环，不导入大量历史文件。

## 内容层边界

正式考试范围与出版标准分别登记，不能混成一个“题库规则”。内容层只描述题目、材料、选项、空格、答案、解析、评分点、来源和审核状态，不知道自己将被排成 B5 还是 A4。

## 当前交付面

- 历史研究与当前仓库状态审计；
- 2023 版考试大纲、2026 管理办法和四科试卷结构登记；
- 出版/语言/数学/印制标准生命周期登记；
- provenance 与不可变 Question ID 规则；
- 四科 profile、readiness matrix 和冷—温—热迁移规则；
- 自拟 fixtures、同源学生/教师生成和 CI/QA 骨架；
- 代表性样册可以重复生成，但不宣称替代教师审核题库。

## 后续可以加入

- 经过授权的代表性来源和文件级哈希清单；
- 2022–2024 语文/政治教师审核记录的结构化迁移；
- 数学公式语义基线和英语旧 DOC 转换实验；
- 公共字体 profile、逐页 Golden Page 和更多 print profile；
- 逐题教师复核后的章节样章。

## 暂不加入

- 未经授权的真题、扫描试卷、商业教辅正文和整批历史文件；
- 邮箱导出的研究原件、私人路径、账号、密钥和个人信息；
- 没有独立来源、审核或时效标记的政治结论；
- 把模拟题、回忆题或二手整理稿命名为官方真题。
