# 从历史资料到可发布样册的迁移计划

## 1. 三层仓储

| 层 | 内容 | 存放位置 | 规则 |
|---|---|---|---|
| cold/raw | 原始 PDF、DOC/DOCX、扫描件、网页导出、原始批注 | 本机研究根目录 | 只读，不复制进公开仓库 |
| warm/normalized | 目录、哈希、结构化摘录、来源记录、审核事件 | 本机私有台账/可审阅导出 | 保留原值和修订关系 |
| hot/publication | 匿名化 fixture、公开样册、学生/教师 PDF | Git 仓库 `fixtures/`、`build/` | 只能接收通过门槛的内容 |

## 2. 首轮四个代表性来源

首轮只选择四类代表，不批量导入本地约 440 MB 历史材料：

1. 语文：一份已有教师审核线索的代表性材料，覆盖文言/阅读和字下点。
2. 政治：一份已有审核线索的材料题，覆盖分值、得分点和时效字段。
3. 数学：一份自足公式与解答 fixture，覆盖上下标、分式/根号和步骤。
4. 英语：一份结构化转录 fixture，覆盖短文、选项、填空线、大小写和混排。

这些 fixture 可以是匿名化或自拟压力样本；若不是公开官方原文，必须使用 `self_authored`/`derived_exercise` 等准确类型，不伪装成真题。

## 3. 阶段检查点

### Checkpoint A：继承完成

- 历史研究索引、版式登记、旧台账映射和边界报告已入库。
- 原始资料仍在原位置，未被改写、移动或删除。

### Checkpoint B：模型完成

- `exam-scope-register.yml`、`standards-register.yml`、题目 schema 和本地来源示例已入库。
- 四科 profile 和成熟度边界已明确。

### Checkpoint C：小样本完成

- 四科 fixture 通过 schema、学生/教师同源检查。
- XeLaTeX 能发现并生成整合样册及四科各一张单页样张；学生/教师源一致，代表页完成彩色/灰度和文本结构检查。

### Checkpoint D：迁移可扩展

- 旧台账字段能映射到 source/question/occurrence/verification。
- 批量导入仍以“候选—人工确认—发布”分层，不把脚本输出直接当成学生内容。

## 4. 暂不承诺

本阶段不承诺全量 OCR、全量题库、自动知识点分类、全量近重复合并、所有年份政治时事更新或四科正式出版。先用少量、可审阅、可回滚的样本验证模型和构建链。
