# 历史教研索引与继承边界

## 1. 目的

本索引把 `LOCAL_RESEARCH_ROOT` 中已有的报告、审核稿、题源台账和版式实验接入公开仓库的模型。它只登记“在哪里、解决了什么、证据到哪一级、下一步是什么”，不复制本地原件，也不把搜索命中或回忆内容提升为官方材料。

## 3. 旧台账的继承映射

现有 `题源台账_2022-2024_政治语文` 系列工作簿已经包含“使用说明、试卷总表、政治/语文题目索引、边界清单、路径与哈希、字典与映射”，后续迁移按下表处理：

| 旧工作簿字段/页签 | 新模型位置 | 迁移原则 |
|---|---|---|
| 试卷总表 | `source` | 一份文件一个 source；来源类型、年份、科目、格式独立保存 |
| 政治/语文题目索引 | `question` + `occurrence` | 旧 `P-2022-Q1` 等 ID 先作为兼容别名，不能覆盖新稳定 ID |
| 边界清单 | `verification_event` / `issue` | 原问题保留；修订不是无痕替换 |
| 路径与哈希 | 私有 source manifest | 绝对路径只留在本机配置，不进入公开仓库 |
| 字典与映射 | `config/` 与 schema 枚举 | 先收敛枚举，再导入题目 |
| 政治审核明细 | `verification_event` | 审核人、日期、题面/答案/解析分开记录 |
| 政治 2022–2024 对照 | `relationship` | 只表达相似、承接、待核验，不制造新的“官方原题” |

## 4. 已知错误/风险应继续保留

- 政治模拟卷中出现“每空 3 分，共 5 分”导致总分不一致的例子；应记录为结构错误，不在发布前静默改分。
- 2026 相关模拟材料出现总分 125 与 150 不一致的例子；年份、材料类型和适用范围必须独立记录。
- 政治题中时事范围、术语混用、答案依据不足，必须由时效字段和审核事件承载。
- 语文、政治 2025–2026 资料多为回忆或二手整理；在状态未达到 `teacher_reviewed`/`cross_checked` 前不得进入学生发布层。

## 5. 使用边界

历史研究可以直接影响：字段设计、状态枚举、版式组件、抽样夹具和审核优先级。
历史研究不能直接授权：公开原题转载、全量题库发布、官方身份声明、未经复核的答案发布。
