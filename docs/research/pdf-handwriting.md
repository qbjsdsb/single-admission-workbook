# 手写题目与手绘图：最低成本接入

## 已落地

PDF 读取不再只看文本长度。扫描/低文本页、已显示的图片（含内联图片）、
矢量绘图和 PDF 批注均进入视觉处理提示；正文可提取不代表图和公式完整。
这只是保守路由，不是手写分类器。表格线、装饰线也会触发，后续可批量确认。
Document AST 保留未解决视觉内容标记，防止文字提取成功掩盖视觉缺失。

```bash
python scripts/prepare_pdf_visual_review.py build/private/source.pdf \
  --out build/private/visual-review
```

按源文件 SHA256 和 DPI 缓存疑难页面图（包含批注），保留全部页码和已提取文字。
默认 180 DPI 用于识别预检，可用 `--dpi 300`；放大低清原稿不能恢复不存在的细节。
完整原页是证据，不直接作为学生册插图：混有答案的页面不能直接进入学生版。
输出仍是待处理内容，不是完成 OCR、自动切题、自动重画或出版批准。

## 推荐后续处理顺序

1. 有可提取文字的区域复用原文字；扫描和手写区域再使用 OCR/视觉识别。
2. 手写文字/公式转成候选正文与 LaTeX，绑定源页和区域坐标。无法确认的符号保留原图，
   不推测补写；尤其核对负号、指数、分母、不等号、角标与加点/划线。
3. 手绘几何图默认保留清晰原图，先完成题图绑定。需要统一画风时再按明确坐标/关系生成
   SVG/TikZ；点名、虚实线、角标逐项对照，避免生成式美化改变题意。
4. 教师手写批注与原题分开；学生版不能携带答案、辅助线或解题步骤。
5. 已确认结果复用，仅把有歧义或不清晰的区域交人工，不重复核查整套资料。

可评估 PaddleOCR 的手写识别与 PaddleOCR-VL 的文档/公式解析，先以真实疑难页做小样本
比较，再决定是否部署；本 PR 不新增大型模型、服务、付费接口或上传原稿。
官方资料：https://paddlepaddle.github.io/PaddleOCR/main/en/index.html
https://github.com/PaddlePaddle/PaddleOCR/blob/main/docs/version3.x/pipeline_usage/PaddleOCR-VL.en.md

抽查数学历年/模拟资料的缩略页，并放大部分公式、扫描和几何图页面；不能据此声称
