# 八册生产效率复核

基于 editorial-queue 分支 1954812。目标仍是四册练习册与四册配套解析册；
现有队列和校验基础已足够，近期优先推进真实内容，避免再增加流程层。

## 本次修改

- 内容匹配成功后，答案使用教师卷的章节与题号；避免学生卷和教师卷题号不同而串答案。
- 教师解析沿用已经绑定的答案证据身份；不再凭学生题号重新寻找解析。
- 其他章节的同号答案不作为回退；无章节答案表仍可在唯一匹配时使用。
- 只有非空解析才能满足样章的教师解析要求；提示语不能代替解析。
- 单命令串联现有八个处理阶段；不引入新框架或新审批层。

## 实测与边界

私有 2021 英语原卷和解析版：端到端预检约 0.214 秒，56 个候选单元，
38 个可进入答案核验，18 个需复核，11 个缺答案；教师补充内容 32 个、未解决 24 个。
编辑队列仍有 56 个待核验、45 个待分类、24 个缺解析、4 个结构问题；问题可重叠。
这些是候选单元和处理状态，不能当作已出版题数；没有自动批准或漏掉未解决题目。
公开仓库只记录统计，不含私有题文。

111 项单元及集成测试通过。另试验了匹配归一化缓存与只取前两名，
100 条合成模糊匹配结果一致，但单次耗时从 1.386 秒变为 1.615 秒；
没有可靠提速证据，因此撤回这项优化。该小样本计时不代表全量性能。

## 下一步顺序

1. 批量运行已有配对与编辑队列，只人工处理异常；复用已确认结果，避免重复审题。
2. 优先完成英语、政治的章节归属和教师解析，各产出一个完整真实章节，
   用现有目录、学生/教师共用题目模型检查页码、题组、插图与分页。
3. 再推进语文、数学的输入适配和公式/题组问题，沿用同一出版流程。
4. 八册交付必须核对“原始题目 → 候选题 → 正式题 → 册/章/题号”覆盖表，
   未解决、重复来源合并与附录题都应有去向；不靠静默丢题提高通过率。

目录功能已有基础，优先真实章节排版验收，不另建独立目录服务。
本次没有编译或视觉验收最终八册，因此不作最终排版质量承诺。
