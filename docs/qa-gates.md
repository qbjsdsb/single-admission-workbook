# 发布质量门槛 Q0–Q8

每个门槛都要有可保存的证据。单次命令退出码为 0 只能证明某一层通过，不能代替整套发布判断。

| 门槛 | 名称 | 必须证明 |
|---|---|---|
| Q0 | 范围与版本 | 题目/材料的科目、考试周期、来源类型和适用范围已登记；官方范围引用可打开或已缓存证据 |
| Q1 | 来源与血缘 | source、哈希/别名、题目 occurrence、审核报告和允许用途可回溯 |
| Q2 | 内容结构 | JSON/schema 通过；题干、选项、空格、材料、分值、答案字段类型正确 |
| Q3 | 修订透明 | 所有改动都有 original/issue/proposed/evidence/status；没有无痕语义改写 |
| Q4 | 渲染环境 | XeLaTeX、中文/英文/数学字体、关键宏包和字下点宏可发现并通过单字/多字/字形/换行回归页 |
| Q5 | PDF 技术 | PDF 可打开、页数非零、尺寸符合 print profile、文本提取正常、无 TeX error/明显 overfull/乱码/空白页；学生/教师均成功生成 |
| Q6 | 页面视觉 | 代表页逐页查看；B5、边界、分页、材料框、答题区、字下点、公式、英文换行满足 profile |
| Q7 | 学科编辑 | 四科各自的内容风险已检查；答案、分值、时效和依据由相应审核人确认或明确标为未确认 |
| Q8 | 发布权限 | 只有达到允许用途和状态的记录进入学生/教师发布层；题目 ID 集合一致、学生版无教师答案标记；报告、构建日志和产物可复现 |

着重点的正文须直接保留在 PDF 文本流中；装饰用下点不应替代或打乱正文。回归页使用内容流顺序提取，忽略提取器插入的 ASCII 句点与排版空白，但必须按原顺序找到标记正文。字下点本身仍须彩色、灰度实际查看。

## 失败处理

失败记录不删除。构建失败、视觉异常、争议题和待核验题进入报告/问题清单，并阻止相应视图发布；可以继续生成 `research_only` 的研究产物。
