# Teacher Enrichment v0.1

Teacher Enrichment moves reviewed teacher-only prose from an Evidence Bank toward a Canonical Draft.

It may attach:

- analysis;
- teacher notes / 题干核心.

It does not alter the verified answer.

Automatic enrichment requires a trustworthy candidate/evidence binding:

- content_exact;
- content_high;
- paired_source_number from an already paired source document.

number_only and none are not sufficient.

Conflicted pairing rows are never enriched automatically. Missing analysis/notes remain explicit unresolved items.

When one source contains several analysis paragraphs for a question, distinct chunks are preserved in source order and joined with line breaks.

Real enrichment output stays private.
