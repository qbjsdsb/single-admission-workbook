# Safe Classification Proposals v0.1

Classification automation is deliberately narrower than parsing automation.

The system may auto-propose a taxonomy placement only when the source structure itself determines the destination under an approved taxonomy.

Current direct English mappings:

- source section `cloze` -> chapter `cloze` / section `cloze_training`;
- source section `writing` -> chapter `writing` / section `writing_training`.

The following are explicitly deferred:

- English single-choice and spelling items: grammar/vocabulary semantics are required;
- English reading items: the source section does not reveal whether an item is detail, inference, main idea, or word guessing;
- all Politics items: a project-approved Politics taxonomy has not yet been derived from the supplied source materials.

Difficulty is provisionally `standard` for direct mappings and must be calibrated later by editorial evidence. A direct proposal is still an editorial manifest entry, not a claim about semantic mastery.
