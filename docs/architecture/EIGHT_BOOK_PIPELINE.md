# 八册自动成书目标与真实边界

目标：语文、数学、英语、政治各一本学生练习册和一本教师解析册。
继续沿用 A4 样张与同源题库；原始资料、提取文本和解析缓存不进入公开仓库。

## 已实现

- `python scripts/workbook.py intake sources.zip`：读取整库、计算指纹、限流并行处理、逐文件原子写入缓存；逐页检查 PDF，不用前五页代表全卷。
- 自动调用 LibreOffice 转换旧 DOC，最多同时两份，31份真实文件已成功转换并提取，仍需保真复核。
- 相同内容复用提取结果；修改提取器或 PDF 引擎版本后缓存失效；失败文件下次重试。
- DOCX 复杂结构明确标记，不将普通文本提取当作公式、加点字和图形的完整还原。
- `python scripts/workbook.py build dataset.json --compile`：验证来源台账和全题库覆盖，按明确章节及难度排序，同时生成八份成书清单和 PDF。
- 缺答案、空解析、未核实来源、题数不符、未分章、重号、漏题均阻止构建；学生教师版顺序相同。
- 内容重复允许归并为一道规范题，所有原始出现位置必须保留；相似题、不同条件或不同答案不可自动合并。
- 编译缓存包含实际 TeX 与 renderer 实现；未变的册复用 PDF。完整状态标记只在八册全部编译后写入。
- 构建成功不等于正式出版审核通过；字体、彩色/灰度视觉、内容准确性仍需独立核验。

## 全部题目都用到的定义

1. 所有原始文件均登记，包括备考笔记中的例题、答案卷中独有的补充题。
2. 每个来源的每次题目出现都有 locator 和规范题 ID，不能仅统计文件数量。
3. 完全重复题可一次排印、多来源映射；非重复题不得因难度、篇幅、年份或章节分配困难而删除。
4. 阅读材料、完形填空和关联小题必须作为不可拆散题组。当前 renderer 尚未完成题组子题支持，严格构建会阻止这两类题，不能假装支持。
5. 非题目资料需记录具体理由；不能把解析失败文件标为“无题目”。
6. 所有规范题在对应学生册、教师册各出现一次。不存在为了平均页数而裁题的配额。

- 富文本 DOCX 到 canonical 的保真适配；已保留逐块 XML、加点/下划线属性、公式 OMML 和图像关联，尚不等于可直接出版。
- 四科学科知识点自动分类与交叉审查；当前编排读取已经审核的 chapter_key/section_key。

- 私有持久化云端运行区及一次上传后自动续跑；公开 Actions 仅运行虚构样例，不上传真实题库。

## 接入数据

参照 `examples/eight-books/dataset.json`（四道自编题，不是真实题库）。
`questions` 为现有 canonical schema；`curriculum` 为按学科排列的章节/小节；
私有 `ledger.expected_source_ids` 必须对应整库冻结清单，不能通过遗漏整个文件来通过覆盖核对。
`ledger.sources` 保存来源 ID、经核实题数与核验状态，
`ledger.occurrences` 保存每次出现的位置和规范题 ID。零题来源必须有 non_question_reason。
学生教师卷配对只是候选关系，不能当作答案匹配已经正确。

## 后续实施顺序

先接入转换/OCR和富文本保真，再做完整逐题台账；优先处理可可靠解析的资料，难件进入独立队列但不丢弃。
自动分类只提出候选，低置信和多知识点题需要复核；优先由代理处理异常，用户只需最终样张与争议内容确认。
最后联动八册构建及全覆盖验收。OCR 和生成解析不以减少用户操作为由降低准确性标准。
