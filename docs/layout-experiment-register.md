# 版式与渲染器实验登记

## 1. 决策原则

渲染器的选择以可重复构建、内容模型接入、字体可发现、学生/教师同源和逐页 QA 为准。单张页面“看起来好”是必要证据，但不是发布结论。

## 2. 实验登记

| 实验 ID | 工具/来源 | 已观察到的优点 | 风险/未决项 | 当前结论 |
|---|---|---|---|---|
| `layout-word-probe` | Word/LibreOffice 试编辑 | 中文长文调整快，便于临时改稿 | 字体、分页、批量再生和差异审计弱 | 仅作临时编辑/对照，不作主渲染器 |
| `layout-typst-b5-v2` | `Typst样张_20260921` | B5 页面舒适、颜色克制、学生/教师布局清楚 | 尚未和本仓库 schema、CI、四科组件完整接通 | 保留为已验证的替代候选，继续留证 |
| `layout-scribus-probe` | `Scribus样张_20260921` | 印刷视觉和页面密度直观 | 手工链路难重建，内容与版式耦合 | 作为视觉参考，不作 v1 基线 |
| `layout-latex-b5` | `LaTeX测试_20260922` 与公开骨架 | XeLaTeX 适合 CI、文本源可审阅、数学和 CJK 生态成熟 | 字体/宏包环境必须显式检查；长材料分页需回归 | v1 公共基线 |
| `layout-dot-mark` | `dot-mark-study_20260922` | 清楚暴露上点与字下点差异 | 多字、换行、粗体、楷体、行末尚未全部回归 | 进入 LaTeX 专用 fixture 和 Q4/Q6 门槛 |

## 3. v1 渲染器决策

v1 采用 XeLaTeX 作为公开仓库基线，原因是：

1. 现有公开仓库已经以 XeLaTeX 为构建入口，迁移成本和审阅路径最低。
2. 数学公式、中文字体、表格、材料框和学生/教师视图可以在同一源码链中表达。
3. 本机 XeLaTeX 已经实际验证可执行；脚本将优先读取 `XELATEX` 环境变量，其次检查 PATH 和已知 MiKTeX 安装登记/目录，不把私人路径写入仓库。
4. Typst 的成熟样张结论不丢失；若后续实现同一内容模型、同等 QA 和稳定字体环境，可作为第二渲染后端。

## 4. 字下点验收矩阵

公共宏 `\marked{...}` 至少需要通过：

| 场景 | 观察点 |
|---|---|
| 单个汉字 | 点位于字下，不漂到字上或行间 |
| 多字短语 | 点数、间距和视觉重心稳定 |
| 行末与换行 | 不产生孤立点、异常增高或断行错位 |
| 粗体、楷体、不同字号 | 点与字形相对位置可接受 |
| 中文与英文/数字混排 | 不覆盖下划线、标点和数学基线 |
| PDF 文本提取 | 下点宏不破坏主体文本提取 |
| 彩色与灰度打印 | 点仍可辨识，颜色不成为语义唯一载体 |

初始仓库模板中的 `\overset` 只能作为历史反例；发布门槛要求使用字下点实现并保留回归截图/日志。
